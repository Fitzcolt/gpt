# Bug Bounty Recon Automation Prompt Pack

## Product intent
A practical prompt system for ethical bug bounty researchers to speed up passive recon, triage, and report drafting while honoring program scope and legal boundaries.

## Included files
- `PROMPT_LIBRARY.md` — 50 production prompts grouped by workflow.
- `SCOPE_AND_SAFETY_POLICY.md` — legal/scope guardrails to ship with the product.
- `SELLER_LISTING_COPY.md` — booth-ready title/subtitle/description/FAQ.

## Buyer quick start (5 minutes)
1. Open `SCOPE_AND_SAFETY_POLICY.md` and paste the policy at the top of your assistant thread.
2. Open `PROMPT_LIBRARY.md` and start with **A1 → A3 → B1** for first-pass recon.
3. Use **D-series** prompts to prioritize leads before spending time validating.
4. Use **E-series** prompts to build a polished submission draft.
