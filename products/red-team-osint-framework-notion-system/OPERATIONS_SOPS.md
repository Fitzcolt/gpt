# Operations SOPs

## 1) Collection SOP
- Record source URL and timestamp for every data point.
- Prefer primary sources over reposted artifacts.
- Tag each entry with confidence: Low / Medium / High.
- Never promote a claim to "Finding" without attached Evidence.

## 2) Evidence hygiene SOP
- Save an immutable archive link where possible.
- Keep original context snippets (not only conclusions).
- Track chain-of-custody notes for sensitive evidence.

## 3) Analysis SOP
- Start from hypothesis, not assumptions.
- Link every inference back to evidence rows.
- Distinguish observed facts from analyst interpretation.

## 4) OPSEC SOP
- Use dedicated profiles/accounts per campaign.
- Separate research identities from personal identity.
- Strip metadata from shared files/screenshots.
- Use need-to-know access on workspace pages.

## 5) Weekly review SOP
- Close stale low-value tasks.
- Re-score high-impact findings.
- Validate assets not checked in 30+ days.
- Publish a one-page campaign status summary.
